Akaun Google & selaras antara peranti

Data disimpan dalam folder app tersembunyi di Google Drive anda. Hanya app ini boleh membacanya.

Cara mendapatkan Client ID (sekali sahaja)
  1. Buka console.cloud.google.com dan buat satu projek.
  2. APIs & Services > Library: aktifkan Google Drive API.
  3. OAuth consent screen: pilih External, isi nama app, dan tambah e-mel anda sebagai Test user.
  4. Credentials > Create credentials > OAuth client ID > Web application.
  5. Authorized JavaScript origins: masukkan alamat tempat fail ini dihos, contoh https://namaanda.github.io (tanpa laluan).
  6. Salin Client ID, tampal di atas, kemudian tekan Log masuk.

Log masuk Google hanya berfungsi apabila fail dibuka melalui alamat https. Ia tidak berfungsi jika fail dibuka terus dari komputer.
