Penyegerakan & offline

Data disimpan pada peranti dahulu, kemudian disegerak ke akaun Google anda.

Sediakan Google (sekali sahaja)
  1. Buka console.cloud.google.com, buat projek, kemudian aktifkan Google Drive API.
  2. OAuth consent screen: pilih External dan tambah emel anda sebagai Test user.
  3. Credentials > Create credentials > OAuth client ID > Web application.
  4. Authorized JavaScript origins: (alamat tempat fail ini dihos).
  5. Salin Client ID ke kotak di atas. Data disimpan dalam ruang tersembunyi app di Drive anda, bukan dalam fail biasa.
